# CaronaUni

O **CaronaUni** é um protótipo acadêmico de um aplicativo de caronas universitárias, criado para facilitar o deslocamento de estudantes e professores até a faculdade.

Este foi o **primeiro mini projeto desenvolvido na disciplina de Projeto e Engenharia de Software durante o 2º semestre da faculdade**. A atividade já foi concluída, apresentada e entregue.

## Sobre o projeto

A proposta surgiu a partir da dificuldade que muitos estudantes enfrentam para conciliar seus horários com o transporte público. Ao mesmo tempo, alunos e professores que utilizam veículos próprios podem ter vagas disponíveis durante o trajeto.

O CaronaUni busca conectar essas pessoas por meio de uma experiência simples, permitindo que usuários encontrem ou ofereçam caronas para a universidade.

## Funcionalidades demonstradas

- Login demonstrativo por e-mail ou matrícula;
- Escolha entre os perfis de passageiro e motorista;
- Busca de caronas por origem, destino e horário;
- Visualização dos dados do motorista, veículo, vagas e contribuição;
- Solicitação de vaga em uma carona;
- Consulta das caronas solicitadas;
- Cadastro de veículo para o perfil de motorista;
- Criação e publicação demonstrativa de uma carona;
- Interface responsiva inspirada em aplicativos móveis.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

O projeto foi desenvolvido em um único arquivo HTML, sem necessidade de instalação de dependências ou configuração de banco de dados.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Para acessar o protótipo, preencha qualquer usuário e senha na tela de login.
